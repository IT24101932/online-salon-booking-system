# 💇 Online Salon Booking System

A modern and responsive **Online Salon Booking System** developed using **HTML, CSS, JavaScript, Spring Boot, and MySQL**. This project enables customers to browse salon services, schedule appointments, and manage their bookings through an intuitive interface. It also includes an admin panel for managing services, staff, customers, and appointments.

## 🚀 Features

### Customer

* User Registration & Login
* Browse Salon Services
* Search Services
* Book Appointments
* View Booking History
* Cancel Appointments
* Update User Profile

### Admin

* Secure Admin Login
* Dashboard Overview
* Manage Services
* Manage Staff
* Manage Customers
* Manage Appointments
* Confirm or Cancel Bookings

## 🛠️ Tech Stack

## ⚙️ Installation

1. Clone the repository.
2. Configure the MySQL database.
3. Update the database credentials in the Spring Boot configuration.
4. Run the Spring Boot backend.
5. Open the frontend in your browser or serve it using a local development server.
